# Issue Tracker

Issues for this repository live in the Linear project `pr-agent`.

Use the configured Linear integration to search, read, create, and update issues. Scope operations to the `pr-agent` project. Add implementation context and progress as issue comments, and keep the issue status current as work moves through triage and delivery.

Pull requests are not a triage request surface. Do not import PRs into the Linear triage queue unless a maintainer explicitly requests it.
