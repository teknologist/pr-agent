# Issue Tracker

Issues for this repository live in the Linear project `pr-agent`.

Use the configured Linear integration to search, read, create, and update issues. Scope operations to the `pr-agent` project. Add implementation context and progress as issue comments, and keep the issue status current as work moves through triage and delivery.

Pull requests are not a triage request surface. Do not import PRs into the Linear triage queue unless a maintainer explicitly requests it.

## Conventions

Linear project: pr-agent (id: e0a76de7-69ba-4c0b-9fae-527612f57b4f)

Use `In Progress` while an agent is actively implementing an issue and `Done` only after all acceptance criteria and review gates are verified. Record implementation progress, verification evidence, review passes, and commit hashes as chronological issue comments. Acceptance criteria are markdown checkboxes in the issue description and must retain their exact text when updated.
